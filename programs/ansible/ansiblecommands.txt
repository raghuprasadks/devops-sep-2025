Vim has modes:

Normal (default) → navigate, delete, copy

Insert → type/paste content

Press Esc to make sure you’re in Normal mode.

1.Delete all content

Type:

ggVGd


Explanation:

gg → move cursor to the top of the file

V → start visual line selection

G → select until the end of the file

d → delete the selected content

Now the file is empty.

2.Enter Insert Mode

Press:

i


You can now paste or type new content.

3.️Paste content (from clipboard)

If you’re in a terminal like Ubuntu:

Right-click → Paste

Or press Shift + Insert

4.Save and exit

Press Esc to go back to Normal mode

Then type:

:wq


:w → write/save

:q → quit

File is now updated with your new content.

11)To install nginx and start nginx on target server using ansible playbook

touch first-playbook.yml

nano first-playbook.yml

paste this inside 

---
- name: Install and start nginx
  hosts: all
  become: yes

  tasks:
   - name: Install nginx
     apt:
       name: nginx
       state: present
   - name: Start nginx
     service:
        name: nginx
        state: started

ctrl + o -> enter -> ctrl + x

12) now to run this use the command below

ansible-playbook -i inventory first-playbook.yml
